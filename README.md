# Harmenszoon's Chat

Shortens player and channel prefixes in Blizzard's chat windows and keeps up to 1,000 recent messages per window during your WoW Forever session. Whisper tabs, player links, and item links retain their native behavior.

To copy text, drag across the words you want and release. In the copy dialog, press **Ctrl+C** on Windows or **Cmd+C** on Mac. You can select part of a line or span several messages. Copying is available for text the game allows addons to read.

## Installation

In WowUp, select **Get Addons**, then **Install from URL**, and paste this repository's address. [Repository URL](https://github.com/Harmenszoon/wow-chat)

For manual installation, extract the `-forever.zip` release asset into `_forever_/Interface/AddOns/` so it contains `Chat/Chat.toc`. [Download the latest release](https://github.com/Harmenszoon/wow-chat/releases/latest)
